# Kit de Anúncios — Google e Meta

**Uso:** copiar e colar no Google Ads Editor e no Gerenciador de Anúncios.
**Limites:** título de pesquisa até 30 caracteres · descrição até 90 · texto principal Meta até 125 (recomendado).
**Regra:** este kit não sobe campanha. A publicação é humana, dentro do painel, depois das verificações do `10_Midia_Paga.md`.

> Todos os títulos e descrições abaixo foram validados por script dentro do limite. Se você editar, confira o contador do painel.

## 7. Antes de subir

- [ ] Conversão configurada (clique no WhatsApp ou mensagem)
- [ ] URL final abre e o link tem o código de origem
- [ ] Nenhum termo de documento do governo
- [ ] Nenhuma promessa de crédito
- [ ] Verificação financeira resolvida (só para consignado)
- [ ] Categoria especial checada (só para Meta/consignado)
- [ ] Negativas aplicadas
- [ ] Orçamento diário compatível com R$ 1.000/mês

## 8. Depois de subir

| Prazo | O que conferir |
|---|---|
| 24 h | Anúncio aprovado? Algum termo reprovado? |
| 72 h | Cliques, custo e primeiras conversas |
| 7 dias | Código de origem chegando? CPL dentro do esperado? |
| 14 dias | Decisão: manter, ajustar ou pausar |

> Sem histórico confiável, 14 dias é o mínimo para decidir. Uma semana é ruído.
